## 功能

1. **開始遊戲**
   - 使用者可以透過「開始遊戲」按鈕開始一局新的暗棋遊戲
   - 遊戲開始後，系統會自動將 32 顆棋子隨機排列在 4 × 8 的棋盤中
   - 所有棋子一開始皆以背面顯示，玩家需要透過點擊棋子進行翻棋
   - 遊戲開始後，「開始遊戲」按鈕會停用，避免遊戲進行中重複開始

   <img width="577" height="346" alt="開始遊戲畫面" src="https://github.com/user-attachments/assets/c0440f98-b29c-4374-ae9b-90a0882e58c1" />


2. **翻棋與陣營判定**
   - 玩家 1 先翻開第一顆棋子
   - 如果第一顆翻到紅棋，則玩家 1 為紅方、玩家 2 為黑方
   - 如果第一顆翻到黑棋，則玩家 1 為黑方、玩家 2 為紅方
   - 翻棋成功時會播放翻棋音效
   - 系統會在上方顯示目前回合方，讓玩家知道現在輪到哪一位玩家操作

   <img width="577" height="345" alt="翻棋與陣營判定畫面" src="https://github.com/user-attachments/assets/944451d7-ffd6-4ba4-80b8-4104abbc5ac5" />


3. **棋子移動**
   - 玩家只能選取自己顏色且已翻開的棋子
   - 一般棋子每次只能往上、下、左、右移動一格
   - 棋子不能斜向移動，也不能跨格移動
   - 移動成功時會播放移動音效
   - 若玩家選取棋子後再次點擊同一顆棋子，系統會取消選取


4. **吃棋規則**
   - 玩家可以使用自己的棋子吃掉符合規則的敵方棋子
   - 一般吃棋規則為大的棋可以吃小的棋，相同等級可以互吃
   - 棋子大小順序為：  
     `帥/將 > 仕/士 > 相/象 > 俥/車 > 傌/馬 > 炮/包 > 兵/卒`
   - 特殊規則：兵/卒可以吃帥/將，但帥/將不能吃兵/卒
   - 不能吃尚未翻開的棋子，也不能吃自己的棋子
   - 吃棋成功時會播放吃棋音效


5. **炮 / 包特殊吃法**
   - 炮 / 包的移動方式與一般棋子相同，只能移動到上下左右相鄰的一格空格
   - 炮 / 包吃棋時，必須與目標棋子位於同一列或同一行
   - 炮 / 包與目標棋子中間必須剛好隔一顆棋子，才可以吃棋
   - 炮 / 包吃棋時不依照棋子大小判斷，只要符合隔一顆棋的規則即可吃掉敵方棋子


6. **剩餘棋數與勝利判斷**
   - 系統會即時顯示紅方與黑方的剩餘棋子數量
   - 當某一方棋子全部被吃掉時，遊戲會判定另一方獲勝
   - 紅方獲勝與黑方獲勝時會分別播放不同的勝利音效
   - 遊戲結束後，棋盤會停止操作，避免玩家繼續移動棋子


7. **重新開始與結束遊戲**
   - 使用者可以透過「重新開始」按鈕重新開啟一局新的遊戲
   - 使用者可以透過「結束遊戲」按鈕結束目前遊戲
   - 按下「結束遊戲」時，系統會跳出確認視窗，避免玩家誤觸
   - 結束目前遊戲後，棋盤會清空，按鈕狀態會回到遊戲尚未開始的狀態
    


8. **遊戲規則說明**
   - 使用者可以透過「遊戲規則」按鈕查看暗棋玩法
   - 規則視窗會說明翻棋、陣營判定、移動方式、吃棋規則、炮 / 包特殊規則與勝利條件
   - 遊戲尚未開始時，也可以查看遊戲規則

   <img width="361" height="355" alt="遊戲規則說明視窗" src="https://github.com/user-attachments/assets/e95eb799-51ae-4297-a76b-764f279ed2fd" />


9. **關閉確認**
   - 使用者關閉視窗前，系統會跳出確認視窗
   - 若使用者選擇「是」，程式會關閉
   - 若使用者選擇「否」，程式會取消關閉，避免誤關視窗

   <img width="574" height="346" alt="關閉確認視窗" src="https://github.com/user-attachments/assets/3c07f576-a049-4c3c-a23d-3c2ed88c4e31" />


## 特色

1. **棋盤與資料分離**
   - 使用二維陣列記錄棋盤中的棋子資料
   - 使用 Button 陣列負責棋盤畫面顯示
   - 移動或吃棋時，會同時更新資料與畫面，讓棋盤狀態保持一致

2. **完整暗棋規則**
   - 遊戲包含翻棋、陣營判定、移動、吃棋、炮 / 包特殊吃法與勝利判斷
   - 透過方法拆分不同規則，使程式邏輯更清楚，也方便後續維護

3. **音效提示**
   - 翻棋、移動、吃棋與勝利皆加入音效
   - 讓玩家在操作時能得到更明確的回饋

4. **防呆設計**
   - 遊戲開始後會停用「開始遊戲」按鈕，避免重複開局
   - 遊戲尚未開始時，無法使用「重新開始」與「結束遊戲」
   - 關閉視窗與結束遊戲時皆會跳出確認訊息
   - 玩家只能操作自己顏色且已翻開的棋子


## 資料來源

- 棋子圖片：象棋棋子圖片素材（來自維基百科）
- 音效：TTSMaker 與免費音效素材
- 遊戲規則：參考一般暗棋玩法，並依照本作業需求進行簡化與實作
